5. Converter Selection

Buck Converter

The Buck converter provides a lower output voltage than the input voltage in its basic ideal continuous-conduction operating region.

Vo ≈ D Vin
D ≈ Vo / Vin
Io = Vo / R
Po = Vo × Io

Buck-Boost Converter

For the classical inverting Buck-Boost converter operating in continuous conduction mode:

Vo = - [D / (1-D)] Vin

For magnitude calculations:

|Vo| = [D / (1-D)] Vin
D = |Vo| / (Vin + |Vo|)
The output polarity of the classical Buck-Boost topology is inverted. The actual relationship depends on the converter topology used in the laboratory. Students must use the equation corresponding to their actual hardware topology.

6. Closed-Loop Control Theory

6.1 Voltage Feedback

e(t) = Vref - Vout

The measured output voltage is compared with the reference voltage. The resulting error is applied to the voltage controller.

6.2 PI Controller

u(t) = Kp e(t) + Ki ∫e(t)dt
D = Saturate(u)

The controller output is converted into a PWM duty ratio.

6.3 Closed-Loop Block Diagram

Vref → (+) → Error → PI Controller → Duty Cycle Limiter → PWM Generator → Power Converter → LC Filter → Vout → Voltage Sensor → Feedback → (-)

6.4 Buck Converter Control

Vref → PI → Duty → PWM → Buck → Vout

6.5 Buck-Boost Converter Control

Vref → PI → Duty → PWM → Buck-Boost → Vout

6.6 Steady-State Error

Ess = Vref - Vout
Error (%) = |Vref - Vout| / |Vref| × 100

6.7 Efficiency

η = Pout / Pin × 100

9. Processor-in-the-Loop (PIL) Implementation

Purpose of PIL

Processor-in-the-Loop testing executes the controller algorithm on the target processor while the plant/model remains in the host simulation environment, depending on the selected PIL architecture.

Typical PIL Workflow

  1. Develop and test the closed-loop controller in Simulink.
  2. Verify stable output-voltage regulation.
  3. Configure the controller subsystem for PIL.
  4. Select the target processor and code-generation configuration.
  5. Generate the controller code.
  6. Build and download the generated code to the target processor.
  7. Establish communication between host and target.
  8. Run the PIL simulation.
  9. Record output voltage, current, duty ratio and controller execution behavior.
  10. Compare normal simulation and PIL results.
The exact PIL configuration depends on the target processor and MATLAB support package. Use the target-specific Hardware Implementation, Code Generation and PIL configuration prescribed for your laboratory.

11. Experimental Procedure

  1. Connect the DC input supply to the converter through appropriate protection.
  2. Verify the Buck/Buck-Boost power-stage connections.
  3. Connect the voltage sensor at the converter output.
  4. Connect the controller input to the scaled feedback voltage.
  5. Build the closed-loop voltage controller in Simulink.
  6. Set the desired reference voltage.
  7. Set the PI controller gains.
  8. Limit the controller output between the minimum and maximum duty cycle.
  9. Generate PWM at the selected switching frequency.
  10. Run the normal Simulink simulation first.
  11. Verify that the output voltage reaches the reference.
  12. Perform step changes in reference voltage.
  13. Perform load changes.
  14. Configure the controller for PIL.
  15. Generate and build the controller code.
  16. Download the generated code to the target processor.
  17. Run the PIL test.
  18. Record output voltage, current, duty cycle and transient response.
  19. Compare Simulink and PIL results.
  20. Repeat the procedure for the second converter topology.
