6. Theory

A buck converter is a DC-DC converter that produces an output voltage lower than the input voltage under ideal buck operation.

Ideal Buck Converter

Vo = D × Vin

where:

  • Vo = average output voltage
  • Vin = input voltage
  • D = duty ratio

Duty Ratio

D = Ton / Ts

Output Current

Io = Vo / R

Output Power

Po = Vo × Io

Input Power

Pin = Vin × Iin

Efficiency

η = (Po / Pin) × 100

8. Procedure

1. Open MATLAB and Simulink.
2. Create a new Simulink model.
3. Place the DC voltage source.
4. Construct the buck converter using MOSFET, diode, inductor and capacitor.
5. Connect the variable load at the converter output.
6. Connect the PWM generator to the MOSFET gate.
7. Set the input voltage to the specified value.
8. Set the switching frequency.
9. Set the required duty ratio.
10. Define the variable load profile.
11. Measure output voltage, output current and inductor current.
12. Run the simulation.
13. Observe the transient response when the load changes.
14. Record the steady-state values.
15. Compare theoretical and simulated output voltage.
