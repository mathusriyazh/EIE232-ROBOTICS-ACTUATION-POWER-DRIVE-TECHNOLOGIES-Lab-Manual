5. Theory

A DC servo motor is a motor used in a closed-loop control system where the motor speed and/or position is continuously measured and compared with the desired reference.

The difference between reference and measured feedback is called the error. A controller processes this error and generates the motor drive command.

Basic Servo Control Loop

Reference → Comparator → Controller → PWM / H-Bridge → DC Servo Motor → Encoder / Sensor → Feedback

DC Motor Equations

Va = Ra Ia + La(dIa/dt) + Eb
Eb = Keω
Te = KtIa
J(dω/dt) = Te - TL - Bω
ω = dθ/dt

Speed Control

Speed Error = ωref − ωactual

A PI controller is commonly used for speed control:

u(t) = Kp e(t) + Ki ∫e(t)dt

Position Control

Position Error = θref − θactual

For position control, the position error can be processed by a position controller to generate the speed reference.

θref → Position Controller → ωref → Speed Controller → Motor

Encoder Position

θ = (Counts / CPR) × 360°

where CPR is the encoder counts per revolution.

Mechanical Output Power

Pmech = T × ω
In a practical servo drive, a cascaded control structure is often used: Position Loop → Speed Loop → Current/Torque Loop → PWM Inverter → Motor. The inner current/torque loop is faster than the speed loop, while the position loop is normally the outer loop.

10. Procedure

A. Speed Control

  1. Open MATLAB and Simulink.
  2. Create the DC servo motor model.
  3. Connect the DC motor to the H-Bridge/PWM drive.
  4. Add the speed measurement block.
  5. Compare the reference speed with measured speed.
  6. Connect the speed error to a PI controller.
  7. Connect the controller output to the PWM generator.
  8. Set the desired reference speed.
  9. Run the simulation.
  10. Observe reference speed, actual speed, armature current and torque.
  11. Apply a load torque change and observe speed recovery.

B. Position Control

  1. Add an encoder or rotational position sensor.
  2. Set the desired position reference.
  3. Compare reference position with measured position.
  4. Use a position controller to generate the speed reference.
  5. Use the speed controller to generate the motor drive command.
  6. Run the simulation.
  7. Observe reference position and actual position.
  8. Measure position error, overshoot and settling time.
  9. Change the position reference and repeat the experiment.
