Experiment 8 – Position Control of Stepper Motor Drive

1. Student Details

2. Aim

To simulate and study the position control of a stepper motor drive using pulse, direction and feedback/control techniques, and to determine the relationship between step pulses, step angle, motor position and position error.

3. Learning Objectives

  • Understand the construction and working principle of a stepper motor.
  • Understand full-step, half-step and microstepping operation.
  • Calculate step angle and number of pulses required for a desired position.
  • Study pulse frequency and motor speed relationship.
  • Implement clockwise and anticlockwise position control.
  • Study open-loop and feedback-based position control.
  • Measure position error and settling time.
  • Study the effect of load torque and pulse frequency.

5. Theory

5.1 Step Angle

The step angle is the mechanical angular displacement produced by one input command pulse in full-step operation.

α = 360° / Ns

where Ns is the number of steps required for one complete revolution.

5.2 Number of Steps

N = θref / α

where θref is the required angular position.

5.3 Position Produced by Pulses

θactual = Np × α

where Np is the number of applied step pulses.

5.4 Pulse Frequency and Speed

Nsteps/sec = fp
Speed (rpm) = fp × 60 / Ns

where fp is the step-pulse frequency in Hz.

5.5 Microstepping

αmicro = α / M

where M is the microstepping factor.

For example, if the motor has a 1.8° full-step angle and 16× microstepping is used:

αmicro = 1.8 / 16 = 0.1125°

5.6 Position Error

eθ = θref − θactual

5.7 Percentage Position Error

Position Error (%) = |θref − θactual| / |θref| × 100

5.8 Position Control

θref → Position Controller → Pulse Generator → Stepper Motor → Position Sensor → Feedback

5.9 Closed-Loop Position Control

e(t) = θref(t) − θactual(t)
u(t) = Kp e(t) + Ki ∫e(t)dt + Kd de(t)/dt
In a practical stepper drive, the controller may command the required number/frequency of pulses and direction. In closed-loop stepper systems, an encoder can be used to detect position loss or following error.

9. Position Control Modes

Open-Loop Control

In open-loop control, the controller assumes that every commanded pulse produces the expected motor step.

Number of Pulses = Required Position / Step Angle
Open-loop control is simple, but excessive load, acceleration or speed can cause missed steps.

Closed-Loop Position Control

In closed-loop operation, the actual shaft position is measured using an encoder and compared with the reference position.

Position Error = θref − θactual
Controller Output = f(Position Error)
Closed-loop stepper control can detect position deviation and compensate for disturbances or missed steps.

Microstepping

Microstepping divides one full step into smaller angular increments. This improves position resolution and can reduce vibration and acoustic noise.

Microstep Angle = Full Step Angle / Microstep Factor

10. Procedure

  1. Open MATLAB and launch Simulink.
  2. Create a new model for the stepper motor drive.
  3. Insert the stepper motor model from Simscape Electrical.
  4. Connect the appropriate inverter/driver to the motor.
  5. Generate phase excitation pulses using a pulse generator or controlled stepper driver.
  6. Provide a direction signal for clockwise or anticlockwise operation.
  7. Set the motor step angle and supply voltage.
  8. Apply the required reference position.
  9. Calculate the required number of pulses.
  10. Run the simulation and observe rotor position.
  11. Measure actual position using the position sensor/encoder.
  12. Calculate position error.
  13. Repeat the experiment for different reference positions.
  14. Repeat using different pulse frequencies.
  15. Apply different load torques and observe position deviation.
  16. Repeat the experiment using microstepping.
  17. Compare open-loop and closed-loop operation.
